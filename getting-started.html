Quick-start guide

Connect your first UPS

Go from an existing NUT server to live Android monitoring in a few straightforward steps.

Before you begin

Make sure your Android device can reach the NUT server on your local network. The default NUT port is 3493.

  1. Install UPSLinkDownload UPSLink from Google Play on the Android device you want to use for monitoring.
  2. Configure your NUT serverSet up NUT on Synology, Unraid, Proxmox, TrueNAS, Raspberry Pi, or another supported platform.
  3. Add a connectionOpen UPSLink and tap Add Connection.
  4. Enter the server detailsProvide your NUT server IP address, port, and credentials if required.
  5. Discover devicesTap Discover Devices to find the UPS devices exposed by your server.
  6. Select your UPSChoose the UPS device you want UPSLink to monitor.
  7. Configure alertsEnable notifications for power outages, low battery, runtime warnings, and connection issues.
  8. Add a widgetOptionally add an Android home screen widget for at-a-glance UPS status.
Synology note

Allow your Android device in DSM

If UPSLink cannot discover your UPS automatically, ensure that Enable Network UPS Server is enabled and your Android device IP address is in the Permitted DiskStation Devices list.

Navigate to Control Panel → Hardware & Power → UPS.
